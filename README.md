---

## Project structure

├── backend/ # NestJS API
├── flutter-mobile/ # Flutter app for athletes

## Tech stack

- Backend: NestJS, PostgreSQL, TypeORM,PGVector
- Mobile app: Flutter
- Auth: JWT access/refresh tokens, cookies
- Logging: Pino logger
